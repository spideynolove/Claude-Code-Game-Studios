# Claude-Code-Game-Studios

A mod version of cc-game-1-man-studios (Claude Code Game Studios).

## Structure

```
.
├── codebase/        # Main fork codebase (the modded Claude Code Game Studios)
├── .claude/         # Tooling scaffold: agents, skills, rules, hooks
├── .agents/         # Agent definitions for other CLI agents
├── docs/            # Project documentation
├── guide/           # Scaffold usage guides
├── plans/           # Plans (templates/) and reports (reports/)
├── scripts/         # Scaffold helper scripts
├── AGENTS.md
└── CLAUDE.md
```

All modifications to the game studio framework happen in `codebase/`. The root-level folders are the engineering scaffold used to plan, review, and document that work.
